# Cryptographic inventory

| Key, algorithm or certificate | Where it may be used | Where it may not be used | What it may protect | What it may not protect |
|---|---|---|---|---|
| The card token key, `Zapper:TokenEncryption:Key`: 32 random bytes, used with AES-256-GCM, a 12-byte random nonce and a 16-byte tag, the stored card's customer reference as the associated data | Only by `CryptographyManager`, in the hosts that encrypt or decrypt a card token | Anywhere else, and never to sign, to hash or to protect any other value | Only `Customer.StoredCard.EncryptedToken` | Any other column, file, message or secret |
| The stub's server certificate: RSA 2048, valid for 365 days, issued by the local authority in `Code/Certificates/ca.crt` for the names `AcmeStub`, `localhost`, `127.0.0.1` and `::1` | Only by `AcmeStub`, on a developer's machine | Any deployed environment, and any other host | Only the HTTPS connections made to `AcmeStub` | Any other connection, file or value |
| The webhook secret, `Zapper:AcmeNotification:WebhookSecret`: random, generated for each environment and shared only with Acme Switch, used as the key of HMAC-SHA256 over a Transaction Status's exact body, compared in constant time with the `x-signature` header decoded from Base64 | Only by `BodySignatureAuthenticationHandler`, in the service that answers requests | Anywhere else, and never to encrypt, to hash or to sign any other value | Only the integrity of a Transaction Status Acme Switch sends | Any other request, column, file or secret |
| The Payment Advice username and password, `Zapper:AcmeNotification:PaymentAdviceUserName` and `PaymentAdvicePassword`: random, generated for each environment and given only to Acme Pay, checked together by comparing the SHA-256 of each in constant time | Only by `BasicAuthenticationHandler`, in the service that answers requests | Anywhere else, and never as a key | Only the proof that a Payment Advice comes from Acme Pay | Any other request, column, file or secret |
| The stub routes' key, `AcmeStub:RoutesKey`: 32 random bytes, generated by `compose.yml` as 64 hexadecimal characters, sent as a bearer key and compared in constant time | Only by `AcmeStub`'s `/stub/` routes, and by the end-to-end script that calls them, on a developer's machine and in CI | Any deployed environment, and never to encrypt, to hash or to sign any value | Only the `/stub/` routes, locally | Any other route, request, file or secret |
